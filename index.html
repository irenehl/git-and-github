Git ≠ GitHub

Git
  • Un programa que instalas en tu compu
  • Guarda el historial de tu proyecto
  • Funciona sin internet
VS
GitHub
  • Un sitio web en la nube
  • Guarda una copia de tus repos
  • Para colaborar y armar tu portafolio

Git es la cámara. GitHub es el Instagram donde publicas las fotos.

Conflictos

Pasa cuando dos ramas cambian la misma línea. Git no adivina: te pregunta a ti.

  1. Respira. No se perdió nada.
  2. Elige una versión (o combínalas)
  3. Borra los marcadores <<< === >>>
  4. git add + git commit
index.html · CONFLICT
<body><<<<<<< HEAD  <h1>Bienvenidos</h1>=======  <h1>Hola, mundo</h1>>>>>>>> feature/saludo</body> # arriba: tu rama actual# abajo: la rama que entra

Error clásico de equipo

¿Y si dos hacen push a la vez?

GitHub acepta al primero. Al segundo lo rechaza hasta que traiga los cambios nuevos, para no borrar el trabajo de nadie.

  1. git pull trae y mezcla lo nuevo
  2. Resuelve conflictos si aparecen
  3. git push otra vez

Comandos de nivel pro

CAJÓNgit stash

Guarda cambios a medias para cambiar de rama sin hacer commit.

REESCRIBIRgit rebase -i

Ordena, une o edita tus commits locales antes de compartirlos.

COPIARgit cherry-pick

Trae un solo commit de otra rama a la tuya.

VERSIONESgit tag v1.0

Marca un commit como versión oficial (un release).

DETECTIVEgit bisect

Encuentra el commit exacto que rompió todo con búsqueda binaria.

RED DE SEGURIDADgit reflog

Historial de todo lo que hiciste. Casi nada se pierde de verdad.
