# Git & GitHub: de 0 a experto

A game-themed slide deck (in Spanish) that teaches Git and GitHub to university students, from the first commit to pull requests and advanced commands.

## Usage

Open `index.html` in a browser, or serve the folder locally:

```sh
python3 -m http.server 8765
```

Controls:

- `→` / `Space` / click: next slide
- `←` / click on the left edge: previous slide
- `Home` / `End`: first / last slide
- `F`: toggle fullscreen
- `#n` in the URL jumps to slide `n`

Requires an internet connection to load the Google Fonts.
